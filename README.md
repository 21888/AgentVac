# AgentVac

一个保守整理 Codex 本地数据的中文桌面应用：先看清空间分布，再预览、隔离旧文件，必要时恢复原位。基于 Electron + Vue 3 + TypeScript。

- **看清占用**：可视化文件分布，区分日志、会话与受保护数据。
- **只读诊断**：分开统计 SQLite、旁路文件和普通日志。
- **可回看、可恢复**：隔离前预览，按批次查看记录并校验恢复。
- **浅色 / 深色主题**：支持手动切换与跟随系统。

## 当前版本与安全边界

当前源码版本为 `0.1.0` 候选版，包含界面布局、对比度、测试夹具和 Linux 打包安全修复。尚未完成全部签名、公证与最终分发安装验收，请先用演示和备份数据验证，不作为已签名正式版使用。

**隔离不等于释放磁盘。** 文件先进入所选目录内的 `.agentvac-quarantine`；移入系统回收站后通常仍占用磁盘。只有用户在操作系统中清空后才可能释放，清空后不可恢复。AgentVac 不提供永久删除功能。

本版不压缩、不删除或清理 SQLite 数据库，不执行 VACUUM、checkpoint 或模式转换，不启动或升级 Codex，也不上传用户文件。

## 第一次使用

1. 先点「体验演示扫描」，练习预览、隔离和恢复。演示使用合成稀疏文件，显示的是逻辑大小，与真实 Codex 数据无关。
2. 用原生文件夹对话框选择 Codex 数据根目录。通常是 `.codex`，也可能由 `CODEX_HOME` 自定义；不要选择项目目录或磁盘根目录。建议位置只是未验证提示，不会自动扫描。
3. 先备份数据，并在「目录与恢复」主动导出恢复备份。备份包含敏感钥匙材料，应离线妥善保管，不要上传或分享。钥匙不能替代文件备份。
4. 扫描后先选少量足够旧的轮转日志，检查保护原因和操作预览。真实隔离前须退出全部 Codex CLI / 桌面进程并明确确认。
5. 在「隔离记录」恢复刚才的批次。已有同名目标不会被覆盖；冲突、文件变化或父目录缺失时保留失败项，按提示处理后重试。
6. 只有确认不再需要的批次才移入系统回收站。系统 API 失败时保留文件，不改用永久删除。回收站还原须先由操作系统恢复整个批次，再由 AgentVac 校验和恢复原位置。

## 功能与保护范围

- 空间分析默认访问最多 50,000 项，可主动改为 100,000 项；另有深度 12 和结果预算 24 MiB 限制。条目数包含目录。达到限制时明确显示扫描不完整，批量选择停用。
- 图表和小计只表示已发现普通文件的逻辑大小，不是整个目录占用、实际分配空间或可释放量。完整扫描也不会展开受保护或未知目录。
- 足够旧的轮转日志可作为候选；当前日志、配置、凭据、数据库、索引及未知文件始终保护。会话 JSONL 默认保护，主动开启复核也不代表它们不再活跃；移走可能影响历史和 resume。
- 不跟随符号链接；多重硬链接、特殊文件和保护天数内文件不可隔离。每批最多 5,000 项，不静默截断。
- 空间诊断支持主动选择的 SQLite / 日志位置，只读统计；深入检查要求支持的日志库结构、稳定身份、无旁路文件及检查前后进程状态均安全。无法满足时拒绝，不降级成可能写入的打开方式。
- 演示工作区会保留操作与恢复状态。重置需再次确认，并通过归属认证和有界检查；未知新增内容会阻断重置。
- 隔离清单由本机恢复钥匙认证。清单已认证不代表数据正文逐字或哈希完整；恢复还会核对文件快照。跨卷复制、换机或系统回收站还原可能改变文件身份，从而拒绝自动恢复。保留批次和原钥匙备份，不手改清单绕过校验。

Renderer 启用 sandbox、context isolation 和 CSP，无 Node 权限。预览短时有效且仅可使用一次，执行前会重新校验。隔离使用同卷 rename；恢复不覆盖已有文件。不在其他不可信用户可写的目录使用，不提权运行，不边运行 Codex 边整理。路径重复检查不能消除所有恶意竞态，也不能保证突然断电或坏盘下的一致性。

## 打包

```sh
npm run dist:mac    # macOS arm64 / x64：DMG、ZIP 构建目标
npm run dist:win    # Windows x64：NSIS、portable EXE 构建目标
npm run dist:linux  # Linux x64：仅 tar.gz
npm run pack       # 当前平台的未归档应用目录
```

构建目标为 macOS 13+、Windows 10+ x64 和受支持的 Linux x64 桌面；请使用仍有安全更新的系统。预构建应用不需要另装 Node.js。

- macOS / Windows：正式分发仍需相应签名、公证与安装验收。不要关闭 Gatekeeper、SmartScreen 或其他系统防护绕过警告。
- Linux：只构建 tar.gz 解包应用。AppImage 已从默认目标移除，避免构建器启动脚本自动关闭 sandbox 的安全降级。通过发行版正规包管理器处理依赖，不禁用 Chromium sandbox、AppArmor 或其他安全策略。系统回收站依赖可工作的桌面 Trash 后端，缺失时操作失败并保留文件。

构建成功或归档完整不等于目标设备已经验收。仓库不包含签名证书或账号凭据，也不自动发布成品。
